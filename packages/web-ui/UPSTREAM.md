# Upstream

This directory is imported from:

- Repository: https://github.com/agegr/pi-web
- Branch: `main`
- Baseline package: `@agegr/pi-web@0.8.9`

The application is kept as a standalone Next.js workspace. It is not registered
as a Pi package in `.pi/settings.json`; it reads the current Pi project
configuration and loads project extensions through the Pi RPC SDK.
